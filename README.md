
# Mantis Blades

A Cyberpunk 2077-inspired wearable cosplay recreation of the Cyberpunk Mantis Blades


## How to Use

- The extension and retraction is controlled by the joystick held in the users hand
- Squeezing the joystick extends the blade to its max
- Releasing retracts it
- The exact extension can be controlled by modulating the joystick
